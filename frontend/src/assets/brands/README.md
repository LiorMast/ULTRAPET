# Brand logos

Logos of the brand cards on the home page. **Name the file after the brand's slug** (`ultra-pet.png`,
`internutri.svg`, `greenheart.jpg`, `paw.svg`, `jr-farm.svg`, `ultra-clean.svg`) and drop it here: it appears on the
card, no code change. Brands without a file show their name as a text wordmark.

- Formats: `.svg` (best), `.png`, `.jpg`, `.webp`. Use a logo on a white or transparent background.
- The three logos here come from the old site's media library.
