# Category photos

The photos on the home page category cards live in this folder. **Drop image files here and they appear on the
site** — no code or settings to change.

- File name = the category slug: `dog-food`, `cat-food`, `wet-food`, `litter`, `small-animals`, `birds`
  (e.g. `dog-food.jpg`).
- Formats: `.jpg`, `.jpeg`, `.png`, `.webp`. Landscape (4:3) photos at least 800px wide work best.
- A category without a photo shows a dark card with its icon.
- The photos are decorative, so they have no alt text. Don't put text inside them.
